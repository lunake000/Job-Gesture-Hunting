# 毕业后做什么工作？

一个面向大学生的中文职业灵感卡牌网页。允许摄像头后，用右手向左挥动即可连续解锁不重复的职业结果；在职业结果卡出现时，用右手比出并保持点赞 350ms，即可展开职业详情。

影像只会在浏览器本地用于实时动作识别，不会上传，也没有外部服务或依赖。右手关键点模型、WASM 运行时和模型文件均已随项目保存于 `vendor/mediapipe/`，可离线运行。

## 运行方式

不需要安装依赖。进入本目录后运行：

```bash
python3 -m http.server 8000
```

然后在浏览器打开 [http://localhost:8000](http://localhost:8000)。

首次点击“开启镜头，开始预测”时，请在浏览器中允许摄像头权限。只接受模型识别到的右手：向左平稳挥动可切换职业；结果出现后，手心或手背朝向镜头都可以，只要拇指竖直上伸且其余四指收拢，并连续保持 350ms 即可查看详情。动态光线会跟随右手掌心轨迹。关闭详情后先松开点赞，再次完成标准点赞即可继续查看；使用本地服务器可让摄像头功能正常工作，直接双击打开 `index.html` 时部分浏览器会阻止镜头访问。
